# kanan-cacao-web — Panel Administrativo Web (Next.js / Vercel)

**Propiedad de:** ASTRA (Agrotecnología y Servicios de Transformación en Recursos Agrícolas de México S.A.S.)  
**Metodología:** AI-Driven Development Life Cycle (AI-DLC)

Panel administrativo web para cooperativas y administradores de ASTRA:
- **HU-03 & HU-04:** Visor de auditoría satelital EUDR (Línea Base JRC 2020) y Salud Vegetal (NDVI Sentinel-2).
- **HU-05:** Verificación administrativa de Certificados Parcelarios y permisos CUSTF de SEMARNAT.
- **HU-06 & HU-07:** Operación de Báscula Ciega (`acopiador`) vs. Monitor de Alertas de *Yield Caps* (`450–650 kg/ha` en Tabasco) y registro GS1 EPCIS 2.0 JSON-LD.
- **HU-09:** Consolidador de minifundios (`< 5 ha`) para mercados voluntarios de bonos de carbono y exportación aduanal TRACES NT.
